# Proyecto: Sitio web para club deportivo en Bakio

## 1. Descripción del proyecto
El proyecto consiste en el diseño de un sitio web para un club deportivo de la localidad de Bakio. Se enmarca dentro del programa educativo del **Bootcamp de Desarrollo Fullstack** de la institución **Peñascal - F5**.

El sitio incluye cinco páginas principales:
1. Inicio  
2. Sobre Nosotros  
3. Servicios  
4. Galería de imágenes  
5. Contacto

## 2. Instalación y configuración
1. Crear una cuenta en [netlify.com](https://www.netlify.com/) con usuario de GitHub.  
2. Iniciar sesión con GitHub.  
3. Crear un nuevo despliegue con previa solicitud de clave de acceso.  
4. Al autorizar, elegir el repositorio a desplegar.  
5. Tras la espera del proceso, se recibe notificación de disponibilidad del sitio en un enlace temporal:  
   [https://tranquil-paprenjak-8312f5.netlify.app/](https://tranquil-paprenjak-8312f5.netlify.app/)  
6. Revisar el sitio con **W3C Validator** a través de la URL proporcionada por Netlify.
